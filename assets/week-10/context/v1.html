A scale primer · LLM parameters

From 1 to 1,760,000,000,000.

Every weight in a neural network is a single number. Modern frontier models hold more of them than there are stars in the Milky Way. Below: every published parameter count, side-by-side with the kind of file you could store in the same memory budget.
