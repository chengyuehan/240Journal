A scale primer · LLM parameters

From 1 to 2,000,000,000,000.

Every weight in a neural network is a single number. How many numbers is that? Here each parameter count shares one line with the tokens of text in books you know — convert a book's word count to tokens (≈4/3 each) and it becomes a plain number you can set right beside a model. From a single page to the Library of Congress.

01Dot leader
A single fixed-width row per model. Dots fill leftward; the number sits at the right. Each extra digit (each ×10) eats one more dot from the left — the "carry" is the visualization.
METHOD · Parameter counts from official model cards, papers, and widely-reported disclosures. MoE totals shown; active-expert counts noted in the label where relevant. GPT-4's count is a community estimate; Llama 4 Behemoth is a preview figure. Book figures use published word counts converted to tokens at ≈4/3 tokens per word — Gatsby 47K words · Moby-Dick 206K · War and Peace 587K · Harry Potter series 1.08M · Encyclopædia Britannica 44M · English Wikipedia 4.7B · Library of Congress ~1.7T words.
