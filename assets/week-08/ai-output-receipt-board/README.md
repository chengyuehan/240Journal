# AI Output Price Receipt Board

Static website package for GitHub Pages or direct local opening.

## Files to upload

- `index.html`
- `styles.css`
- `app.js`
- `data/data.js`

## Notes

- No API key is included in this folder.
- The site does not call an API at runtime.
- Model pricing data is already bundled in `data/data.js`.
- Open `index.html` directly, or deploy this folder with GitHub Pages.

For GitHub Pages, set the Pages source to the branch/folder that contains this `index.html`.
