## Makes it easier

If you’ve found this page, you’ve probably figured out that you can search by repository name to find examples from previous students. If you’re lucky enough to have come across my page in one of your first few searches, I can make the rest of that search a little easier.

I used Claude to match a number of journals from students in 2026 S1. You can browse through them to see what everyone worked on, or get ideas for writing your weekly journal entries. This assumes the course stays the same next year, though—it was revised this year.

**Matching criteria:** The repository’s `README.md` is byte-for-byte identical to the uploaded file (Git blob `945644ab…`, 3,591 bytes). GitHub Pages URLs follow this format: `https://<username>.github.io/<repository>/`.

Project summaries were generated by GPT-6 Luna. Please let me know if you spot any errors. Links may stop working if students close their repositories or for other reasons.

## Course review

In my opinion, the revised course is a welcoming and open-ended design elective. When I chose it, I read the 25S1 course outline. At the time, coding was assessed through a quiz. Based on the outline and my conversations with the teaching staff, the coding component had previously focused on Processing.

The revised course is more inclusive: you can create your final data visualisation in any format. The first half of the course is especially interesting and practical compared with other design electives. If you plan to use code in your final project, taking the earlier material seriously will give you a useful foundation. The material is valuable even if you don’t make a coding-based project, and it is an essential part of the first 40% of the course.

Attendance has a significant impact on your experience, but missing classes won’t leave you completely stuck. All course materials are updated on Canvas. However, some in-class activities involve recording feedback from other students, which you can’t make up if you’re absent. I ran into this problem myself: I missed several classes where I needed to collect feedback, and that affected my grade.

The Journal is the only submission for the course, and it needs to include all your projects, so writing it well takes some effort. Looking up a Markdown guide to learn syntax that wasn’t covered in class can help your website stand out. Or you can ask AI to write the Markdown for you—it’s vibe generation, right?
